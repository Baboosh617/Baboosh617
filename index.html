Machine learning

Grid Stability Predictor

A classification model that predicts power grid stability from electrical parameters, served as a Streamlit app. Grid instability causes cascading blackouts; catching it early is cheaper than recovering from it. 98.7% accuracy on held-out test data.

Data cleaning took longer than modelling. One pipeline bug took 2 hours. It was a missing comma.

// 03 — Approach

How I approach problems

  1. 01

    Understand the system

    Map the problem first. No code until the logic is clear.

  2. 02

    Break it into parts

    Isolate each piece, test it, then put them back together.

  3. 03

    Iterate until stable

    Ship early, refine on real feedback, skip premature perfection.
